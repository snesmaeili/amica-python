`fit_ica` now fits the estimated numerical rank of the data when `n_components` is not given, emitting a `RuntimeWarning` with the value chosen, and raises `ValueError` when an explicit `n_components` exceeds that rank. Previously the default kept every channel: on average-referenced EEG the trailing PCA direction has near-zero variance, which made the unmixing matrix numerically singular, collapsed `mixing_matrix_`, and caused `ICA.apply()` to return near-zero data with no warning.
